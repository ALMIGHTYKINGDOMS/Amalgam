# Amalgam 1.0.0 — Beta Tester Guide

## Getting Started

1. Extract `amalgam-1.0.0.zip`
2. Run `amalgam_launcher.exe`
3. Create an AI Profile from the profile screen
4. Start chatting — AI is built-in

## AI Features to Test

### Chat
Type a message and press Enter. Try:
- "Create a simple KubeJS item that gives speed"
- "What mods would you recommend for a tech modpack?"

### Art
Switch to Art mode and try:
- "Create a dark fantasy sword texture"
- "Make a pixel art diamond pickaxe"

### Vision
Open Minecraft, then click "Start Live Vision" in the AI tab.
The AI will describe what it sees on screen.

### Agent Mode
Ask the AI to modify project files:
- "Add a KubeJS script for a custom crafting recipe"
- Then check the checkpoint system (Undo)

## What to Report
- Any crash or hang
- AI giving wrong/broken code
- Art generation failure
- Vision not working with Minecraft open
- UI glitches or misalignment
- Performance issues

## How to Report
Send feedback to the Amalgam support Discord or email.
Include: Windows version, RAM, GPU, what you were doing, what happened.
