# Amalgam 1.0.0 — User Guide

Welcome to Amalgam! This guide covers installation, setup, and basic usage.
Full details in `RELEASE-NOTES.md` in the installed package.

## 1. Install

Run `AmalgamLauncher-1.0.0-Setup.exe`. It installs to your user folder — no
admin rights needed, and it never touches your Minecraft worlds or official
launcher data.

## 2. Sign in

Use your Microsoft account (needs a Minecraft: Java Edition license) from
**Account** → **Sign In with Microsoft**, or create an Amalgam account.

## 3. Create or import a profile

- **New**: Profiles → Create → pick a Minecraft version and loader (start
  with Vanilla, then Fabric).
- **Import**: point at an existing `.minecraft`-style folder.

## 4. Launch Minecraft

Press **Play**. Amalgam downloads the version, resolves Java, and starts
Minecraft. Your first launch downloads a few hundred MB — give it time.

## 5. Test the launcher and client

- Discover → search Modrinth/CurseForge → install into a profile.
- Library → verify the profile shows installed content.
- Play → confirm Minecraft reaches the main menu.
- Essentials → send a friend request, host a world, test a join.
- Servers → create a local server, start it, check the console.
- Settings → adjust Java, Performance, Appearance, Notifications.

## 6. Report issues

Use **Settings → Send feedback** or the in-app bug report button.
Include:
- What you expected
- What actually happened
- Steps to reproduce
- Screenshot if possible

## 7. What to look for

- Clean install and first-run experience
- Auth persistence across restarts
- Download speed and reliability
- Profile creation and switching
- Server start/stop and console
- Essentials friend and session flow
- Bedrock detection and add-on import
- Settings save and restore

## 8. What's NOT expected yet

- Cloud hosting (coming soon)
- Advanced Bedrock scripting (experimental)
- Full TURN relay testing (needs two devices)

## 9. Uninstall

Use Windows **Add or Remove Programs** or the uninstaller in the
installation folder. Profiles, worlds, and settings are preserved by
default.
