# Amalgam Branding

These PNG and SVG assets are the default Amalgam visual identity:

- `amalgam-mark.svg` is the square app/client mark.
- `amalgam-banner.svg` is the README and release-page header.
- `amalgam-logo.png` is the supplied transparent logo used by the launcher sidebar.
- `amalgam-banner.png` is the supplied visual banner used by the launcher Home hero and README.
- `amalgam-discover-hero.png` is original Minecraft-inspired voxel artwork for
  the launcher Discover hero.
- `amalgam-cover-portal.png`, `amalgam-cover-forge.png`, and
  `amalgam-cover-sky.png` are original Minecraft-inspired voxel fallback covers
  for local/custom profiles. Provider artwork remains preferred whenever a
  Modrinth or CurseForge project supplies it.

The mark uses a neon-violet geometric A, orbit, and diamond for the launcher/client identity. The SVGs are intentionally dependency-free and can be converted to PNG/ICO during a signed release build when platform-specific artwork is needed.

The generated scene art contains no third-party logo, text, named character, or
copied location. It is launcher-provided scenery rather than provider project
artwork and is labeled in the UI accordingly.
