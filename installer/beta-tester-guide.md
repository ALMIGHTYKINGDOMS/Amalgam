# Amalgam Beta Tester Guide

## Welcome
Thank you for participating in the Amalgam Launcher beta! This guide will help you get started.

## Quick Start
1. Run `amalgam_launcher.exe` from the installation folder
2. Sign in with your Microsoft account (device-code flow — you'll visit microsoft.com to authorize)
3. Create a profile and select your Minecraft version
4. Click Play to launch!

## What's Included
- **Launcher**: Modern ImGui-based Minecraft launcher with dark theme
- **Java Bridges**: Supports Fabric (1.18.2-1.21.11), NeoForge (1.21.1-1.21.8), Forge (1.20.1)
- **Mod Manager**: Browse and install mods from Modrinth and CurseForge
- **Essentials**: Friends list, invites, and local multiplayer sessions
- **Server Hosting**: Create and manage local Minecraft servers
- **In-Game Overlay**: HUD with FPS, coordinates, ESP, radar, and more

## Key Features to Test
- **Profile creation and management** — Create multiple profiles with different MC versions
- **Mod installation** — Search and install mods from the Discover tab
- **Server hosting** — Create a local server and test start/stop
- **Essentials** — Add friends and test local session hosting
- **In-game overlay** — Press INSERT to open the overlay menu in-game
- **HUD customization** — Drag and resize HUD elements

## Reporting Issues
Use the **Send Feedback** button in Settings to report bugs or suggest features. Feedback is saved locally and can be exported.

## Known Limitations
- Direct Microsoft login is temporarily disabled (use device-code flow)
- Server hosting and Essentials multiplayer require Supabase deployment for remote features
- Bedrock Edition support is in beta
- Some features are intentionally gated and are not included in this release

## System Requirements
- Windows 10/11 (64-bit)
- Microsoft Visual C++ Redistributable (auto-installed if missing)
- Java 8, 11, 17, or 21 (auto-downloaded if needed)
- Minecraft Java Edition license
